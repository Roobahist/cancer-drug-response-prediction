# Cancer Drug Response Prediction

Reproducible bioinformatics and machine learning analysis using gene expression and molecular features.

This repository is being modernized from a collaborative research project by David Enoma, Sasha Chernenkoff, Ariel Ghislain Kemogne Kamdoum, and Mojtaba Kanani Sarcheshmeh. Original source: https://github.com/davidenoma/DL_cancer_drug_response

The original project reports a best CNN test MSE of 1.160 and R² of 0.832 for LN_IC50 prediction. These historical results are **not yet independently reproduced** because the training data is not included in the source repository.
